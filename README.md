## AsureCore

Центральный плагин с различными полезными возможностями, разработанный для проекта Asure Nova.

Данный плагин включает в себя дополнительные настройки, параметры, элементы интерфейса (GUI), исправления и прочие 
возможности, которые не являлись достаточно крупными, чтобы находиться в отдельном плагине, либо же которые с архитектурной
точки зрения было оптимальнее интегрировать в уже имеющийся центральный плагин.

## Модули и возможности

- **Messages.Join/DefaultJoin/Leave/DefaultLeave:** Настраиваемые сообщения входа/выхода
- **Messages.Death/Advancement:** Настраиваемые сообщения о смерти и о получении достижений
- **Messages.Do/Me/Try:** Команды do/me/try с специализированными форматами текста и параметрами
- **Messages.RightClickNickname**: Отображение никнейма игрока в ActionBar в специализированном формате при нажатии ПКМ по игроку
- **StarterHints**: Отображение советов при входе на сервер через определённые промежутки времени с настройкой лимита наигранного времени,
после которого советы больше не отображаются
- **PlayerLimit**: Настраиваемый лимит игроков на сервере, не требующий рестарта, с возможностью обхода лимита при наличии пермишена
- **DynamicMobCaps/DynamicDistance**: Настройка динамических лимитов мобов и дальности прогрузки чанков, изменяющихся в зависимости от количества игроков на сервере
- **PvPMode**: Переключение PvP-режима с различными условиями (дистанция от игроков, время после последнего переключения) с отдельным 
плейсхолдером и обозначением
- **Tweaks.RepairCostFix**: Возможность отключения лимита при зачаровании или починки предметов (сообщение "Слишком дорого!")
- **Tweaks.GrindstoneDisenchant**: Возможность сохранять зачарования предметов, используя точильный камень.
- **Tweaks.AgeLock**: Блокировка роста животных, используя указанный предмет (неактуально с версии игры 26.1).
- **Tweaks.VillagerOptimizer**: Оптимизация жителей путём разрешения торговли с ними только после отключения их интеллекта.
- **Tweaks.VillagerManualBreed**: Размножение жителей напрямую нажатием по ним ПКМ с указанным предметом в руке.
- **Tweaks.CopperGolem**: Оптимизация медных големов путём отключения их интеллекта при создании. Один игрок может активировать
максимум указанное количество големов.
- **Tweaks.AnvilRepair**: Починка блока наковальни используя указанный предмет.
- **Tweaks.PortalRedirect**: Замена телепортации игрока из указанного мира на выполнение указанных команд.
- **Tweaks.MaceDenier**: Отключение урона булавы по сущностям с указанными именами.
- **Tweaks.ItemLock**: Блокировка указанных предметов, позволяющая запретить их использование в крафтах или же запретить использование
указанных команд при наличии заблокированного предмета в руке.
- **Tweaks.ItemSign**: Возможность подписать предмет, добавив в его описание строку с никнеймом игрока, подписавшего предмет, а также
запрещая использование указанных команд при наличии подписанного предмета в руке.
- **Tweaks.EntityPortalBlock**: Блокирование телепортации сущностей в миры указанного типа. Свойство Remove позволяет
удалить сущность вовсе при попытке телепортации.
- **Tweaks.HideDeathMessages**: Скрытие сообщений о смерти после достижения определённого количества смертей за указанный период.
- **Tweaks.CauldronTransform**: Преобразование указанных предметов из одного типа в другой при забрасывании их в котёл.
- **Tweaks.HeadDrops**: Выпадение головы игрока при его убийстве другим игроком. Может быть отключено командой или выдачей пермишена.
- **Tweaks.VaultReset**: Обновление хранилища зала испытаний после его открытия игроком.
- **Tweaks.DeathKnockout**: Оглушение игрока вместо смерти от рук другого игрока. Может быть отключено командой или выдачей пермишена.
- **Tweaks.HealthSave**: Сохранение здоровья игрока в PersistentDataContainer после выхода с сервера. Применяется в основном в связи с прочими плагинами.
- **Tweaks.UnstripLogs**: Возвращение брёвнам коры (реверс обтёсывания) при использовании указанного предмета.
- **Tweaks.RemovePodzol**: Замена подзола обратно на дёрн при использовании указанного предмета.
- **Tweaks.ColoredHelmetTeams**: Отключение урона игроков друг по другу при ношении ими кожаных шлемов, окрашенных в один и тот же цвет.
- **Tweaks.PhantomsToggle**: Отключение спавна фантомов командой.
- **Compatibility.LiteBans**: Интеграция с плагином LiteBans. Выполнение заданных команд при бане/мути/кике игрока и при обратных действиях.
- **Compatibility.LuckPerms**: Интеграция с плагином LuckPerms. Используется при трансфере данных игрока на другой никнейм и при получении данных плейсходера VIP-группы.
- **Compatibility.AccountTransfer**: Перенос (транфер) данных игрока с одного никнейма на другой. Для переноса инвентаря требуется плагин CMI.
- **OreAlerts**: Отображение модераторам и администраторам сообщений о добыче игроками определённых блоков (например, алмазной руды или незерита). Позволяет отслеживать возможное использование X-Ray и прочих подобных читов.
- **CommandFilter**: Фильтр команд, использующий Regex. Не позволяет отправить команду, если она соответствует любому из указанных регулярных выражений.
- **Mailbooks**: Письма-книги, отправляемые командой. Позволяет игрокам обмениваться посланиями вне общего чата.
- **ArmorStandInteractions**: Настройка позиции стойки для брони с применением отдельного GUI.
- **ShulkerDupeDetector**: Отслеживание дюпов шалкер-ящиков на основе UUID, присваемого каждому шалкер-ящику при создании. 
Учитывает как размещение вручную, так и через раздатчик.
- **CauldronRecipes**: Возможность крафта предметов через котёл. Для крафтов используется отдельный конфиг-файл.
- **DisableDrops**: Отключение дропа указанных предметов из блоков при их добыче.
- **CustomPortals**: Создание незер-порталов с указанными блоками по углам, которые при входе вместо телепортации выполняют указанные команды.
- **ConfirmationStatus**: Возможность по команде присвоить игроку специальный статус и пермишен.
- **CommandsAfterLastSeen**: Выполнение указанных команд, если игрок не заходил на сервер дольше заданного промежутка времени.
- **PingAlert**: Отображение сообщения в консоли при обнаружении высокого среднего пинга среди игроков сервера, а также создание события HighPingDetectedEvent.
- **Guide**: Проведение экскурсии для новых игроков на сервере игроками с заданными пермишенами.

## Сборка

Для компиляции требуется JDK 25 или выше.\
Чтобы запустить сборку, скопируйте проект и запустите сборку через `gradle build`.\
Для одной из зависимостей требуется наличие локального артефакта плагина AsureLib (VineriumLib). Путь до артефакта должен 
выглядеть следующим образом относительно папки проекта: `../VineriumLib/build/libs/VineriumLib-1.0-SNAPSHOT.jar`.\
Скомпилированный артефакт будет находиться в папке `build/libs/`.

## Поддержка

Данный плагин разрабатывался для конкретного проекта. Многие возможности плагина были созданы с целью закрыть определённую нишу в
контенте, и могут являться рудиментарными для остальных проектов. При необходимости каждую конкретную функцию плагина можно отключить или перенастроить.

В связи с предназначением плагина услуги по его поддержке предоставляются только в рамках оригинального проекта. Для получения
поддержки (исправление багов, добавление возможностей) в рамках стороннего проекта, вы можете обратиться к автору плагина и оформить заказ консультации.
